# Southern city extension

Five public tiles extend the 20-tile town to 25, with the old coordinates and public-place indexes unchanged. Borgo Sud and Via dei Tigli contain Lombard residential facades, Piazza Fontana a decorative fountain square, Giardini a public garden, and Stazione a decorative station plaza (no train service yet). All five connect to the existing walking road grid and appear on the map and destination menu. Adjacent walks involving the new districts take eight game minutes; longer transfers use 14 or 18. The default server population seed target rises from 48 to 56; newly generated residents with index >48 sometimes visit the new districts after work. No new home-unit addresses, jobs or functional train service are introduced. Existing save files are retained. Chunk caching continues to load only the current district and immediate neighbors. Test fixture population counts remain unchanged.
