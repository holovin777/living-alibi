# Transportation 1.0 — optional realistic models

From the repository root: `bash tools/install-realistic-vehicles.sh` (once), then `bash play.sh` or `bash play.sh --wide` as usual. The launcher imports the local GLB files. The installer checks the glTF 2 header, file length and JSON scene/mesh metadata before moving the download into place. It never touches the world save and does not install OS packages. Offline or missing files keep the bundled Kenney models working. To revert, remove the three downloaded GLBs and restart.

The pack adds a sedan, hatchback and SUV in both the original and real-map scenes. The models have interiors and separate wheels according to their author; the existing cockpit, driving physics and traffic stay unchanged. Imported wheels are marked for the original scene's existing animation. Paint material overrides are local to each instance. Uniform scale fits existing lanes and parking. The van, bus, trucks, police and emergency models are not replaced yet. Models are 143k–157k triangles before import; Godot's default mesh LOD may help, but performance and appearance on actual hardware have not been verified.
