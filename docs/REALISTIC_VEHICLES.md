# Transportation 1.1 — automatic realistic vehicles

Run `bash play.sh`, `prime-run bash play.sh`, or `bash play.sh --wide` as usual. Both launchers automatically install missing models before Godot imports assets. Valid local files are reused. No sudo or world changes; a failed download does not prevent the game from starting. For offline play set `LIVING_ALIBI_SKIP_VEHICLE_DOWNLOAD=1`. To retry manually, run `bash tools/install-realistic-vehicles.sh`.

The five GLBs are Sport Sedan, Hot Hatchback, Luxury SUV, City Van and Minibus by vinish.dev, CC BY 4.0 (credits in godot/assets/vehicles/CREDITS.md). Both game modes use the same loader. The short municipal bus uses the compact 15-seat minibus exterior, not a full-size 12 m bus, to preserve the current routes and collision envelopes. The original passenger journey interior, driving physics, Java schedules and vehicle identities are unchanged. The original scene uses the existing door state to move the imported sliding door if that node exists. The real-map bus uses the same model with its existing registration logic. Trucks, police and emergency models are unchanged.

Godot's normal GLB importer generates mesh LOD by default; imported vehicle meshes use a 0.65 LOD bias, and named seats/headrests/pedals stop rendering beyond 32 m with a 4 m margin. This is a first pass, not bespoke LOD0/1/2 assets. Hardware FPS, actual GLB imports and door placement require testing with downloaded files. Asset validation checks GLB header, length, JSON and embedded dependencies. Missing models fall back to bundled meshes.

## Transportation 1.2
The installer also downloads City Bus and Box Truck. The district bus stop can use the nearly full-size city bus on straight lanes with clearance for the extended platform; otherwise it uses the compact minibus. The geographic reserve bus remains compact. Freight parking in both modes uses a uniformly scaled box truck to preserve existing collision envelopes. Fire engines retain the procedural truck chassis. Imported wheels preserve their original local orientation and spin in the appropriate direction. The large bus door leaves rotate about their imported pivots. No new freight or passenger simulation is introduced. Actual asset import, clearance in play, and FPS still need visual validation.
