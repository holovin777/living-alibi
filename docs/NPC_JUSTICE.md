# NPC justice prototype

Only a newly confirmed theft case, resolved through the existing accusation procedure, queues a fictional court review. A generated living adult NPC (not the player-linked adult or the legacy Marco/Elena) receives a two-day abstract custodial sentence after a one-day delay. During custody, the NPC does not follow its ordinary work and travel schedule; basic needs are maintained. The office has a private custody scene, not a walkable prison interior. Releases resume the ordinary schedule. The same case cannot impose a sentence twice. No retroactive sentences for already solved saves, no automated conviction based on faction membership, no real legal standard is implied. The current case-resolution interface is the console; this does not yet provide a Godot detective UI or autonomous police investigation.
